# llm-for-the-poors

Run an **agentic coding LLM** on the GPU you already own. No cloud, no invoice — just
llama.cpp on Vulkan, a few glue scripts, and a 7–8B model that calls tools. This repo
turns the whole thing into a LAN OpenAI-compatible endpoint that
[opencode](https://opencode.ai) (or any OpenAI client) can drive.

Built and tested on an **AMD RX 6600** in an 8 GB box.

## Quick start

```bash
git clone https://github.com/ezk06eer/llm-for-the-poors.git && cd llm-for-the-poors

./install.sh                                          # llama.cpp (Vulkan) + venv + kompact + HF token
./manage_deepseek.py install --quant Q2_5_C7B         # download the model (4.7 GB, see table below)

./llm.sh start                                        # full chain live on :8000
curl http://127.0.0.1:8000/health                     # -> {"status":"ok"}
```

Put the example provider config on any machine you want to use as the agent:

```bash
cp examples/opencode.jsonc ~/.config/opencode/opencode.jsonc
# set LLM_SERVER_IP to your GPU box, then:
opencode run --model local/qwen "write hello.py and run it"
```

## Architecture

```
your LAN                                          this server (127.0.0.1)
┌──────────────┐    ┌──────────────────┐   ┌─────────────────────────┐   ┌─────────────────────┐   ┌────────────┐
│ opencode     │───►│ kompact :8000    │──►│ toolup proxy :8001      │──►│ llama-server :8002   │──►│ RX 6600    │
│ (any PC)     │    │ context          │   │  • OpenAI tool_calls     │   │ llama.cpp (Vulkan)   │   │ (Vulkan)   │
│ /v1/chat/…   │    │ compression      │   │  • short system directive│   │ prebuilt binary      │   │            │
└──────────────┘    └──────────────────┘   └─────────────────────────┘   └─────────────────────┘   └────────────┘
     http://SERVER:8000/v1                      127.0.0.1:8001              127.0.0.1:8002
```

Three hops, three problems solved:

1. **llama-server (:8002)** — prebuilt llama.cpp with the Vulkan backend, pulled by
   `install.sh` (no compilers). `-ngl 99` puts the whole model on the GPU;
   roughly 40 tokens/s on a 7B Q4_K_M.
2. **toolup proxy (:8001)** — makes llama.cpp speak OpenAI-compatible `tool_calls`:
   - rewrites llama.cpp's raw tool output into the OpenAI `tool_calls` array
     (`finish_reason: "tool_calls"`), streaming and non-streaming;
   - replaces oversized agent system prompts with a short "take direct action"
     directive (threshold: `SYSTEM_MAX`, default 1050) — without this, small
     models answer "Hello! How can I help?" and never call a tool;
   - auto-applies the correct chat template for models that ship a gutted one
     (`llama/hermes2pro-tool.jinja` for Hermes).
3. **kompact (:8000)** — [context-compression proxy](https://github.com/npow/kompact)
   between you and :8001: TF-IDF tool-schema optimization, extractive/JSON/code
   compression, history management. Cuts 40–70% of the tokens, which is what
   makes the 8K-context models survive real agent sessions. If it ever botches a
   call, `LLM_KOMPACT_OPTS` disables any transform (e.g. `--disable schema_optimizer`).

## Models

No models are shipped. Pick one below and `manage_deepseek.py install --quant <key>`
downloads the GGUF on first run. The `FILES` table in `manage_deepseek.py` is the
full list (repo id + file + size); links here point to the exact repos tested.

| key | model | GGUF | size | use |
|-----|-------|------|------|-----|
| `Q2_5_C7B` | Qwen2.5-Coder-7B-Instruct | [bartowski/Qwen2.5-Coder-7B-Instruct-GGUF](https://huggingface.co/bartowski/Qwen2.5-Coder-7B-Instruct-GGUF) (Q4_K_M) | 4.7 GB | **default** — best agent behavior, 32K native context |
| `HE8B` | Hermes-2-Pro-Llama-3-8B | [bartowski/Hermes-2-Pro-Llama-3-8B-GGUF](https://huggingface.co/bartowski/Hermes-2-Pro-Llama-3-8B-GGUF) (Q4_K_M) | 4.9 GB | uncensored; 8K context wall — pair with kompact |
| `Q3_K_M` / `Q4_K_M` | DeepSeek-Coder-V2-Lite-16B | [bartowski/DeepSeek-Coder-V2-Lite-Instruct-GGUF](https://huggingface.co/bartowski/DeepSeek-Coder-V2-Lite-Instruct-GGUF) | 8–10 GB | the original motivation; barely fits 8 GB VRAM |
| `ML8B` | Meta-Llama-3.1-8B-Instruct | [bartowski/Meta-Llama-3.1-8B-Instruct-GGUF](https://huggingface.co/bartowski/Meta-Llama-3.1-8B-Instruct-GGUF) (Q4_K_M) | 4.9 GB | no tool template — chat only |
| `ABL8B` | Meta-Llama-3.1-8B-Instruct-abliterated | [bartowski/Meta-Llama-3.1-8B-Instruct-abliterated-GGUF](https://huggingface.co/bartowski/Meta-Llama-3.1-8B-Instruct-abliterated-GGUF) (Q4_K_M) | 4.9 GB | refusal-directions stripped; rambles, kept for science |

## Commands

```bash
./llm.sh start|stop|status     # whole chain (kompact + proxy + llama-server)
./manage_deepseek.py status    # current model + backend
./manage_deepseek.py chat      # bare interactive session
./manage_deepseek.py verify    # GPU smoke test + tokens/sec
./manage_deepseek.py install --quant <key>   # download/change the model
python3 agent.py "compute 5*7 with the python tool"   # tool-loop agent, no opencode needed
```

Change the served model on a running system: `echo HE8B > .quant && ./llm.sh stop && ./llm.sh start`.

## Configuration

| env var | default | effect |
|---------|---------|--------|
| `LLM_CTX` | `16384` | context window for llama-server |
| `LLM_KOMPACT_OPTS` | `--no-otel --disable observation_masker --disable cache_aligner` | kompact transform switches |
| `SYSTEM_MAX` | `1050` | system-prompt length that triggers the short-directive swap |
| `LLAMA_SERVER_DIR` | `llama/llama-native` | prebuilt llama-server location |
| `LLAMA_CHAT_TEMPLATE_FILE` | auto (Hermes) | custom Tool jinja applied by model basename |
| `KOMPACT` | `~/kompact/bin/kompact` | kompact binary path |

## Known limitations

- 7–8B models on a budget GPU call tools, execute steps, but sometimes wander off or
  answer conversationally instead of working. That's the model, not the plumbing.
- Vulkan only (AMD/Intel). An NVIDIA box would want CUDA instead.
- Hermes and Llama-3.1 GGUFs cap at 8192 context; rope-scaling flags don't extend
  these builds' trained context.
- `agent.py` executes Python with no sandbox — keep untrusted prompts away from it.
- The free HF token is stored in your shell rc; keep that file private.
